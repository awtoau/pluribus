# MachXO2 EFB: config payload and input-side oracle

Vendor oracle: Diamond 3.14, `scripts/efb_oracle.py` (build, report, compare). One attribute changed per build against the SPI-slave default; payload read by the native decoder (`.efb_block`). Builds took 1-7 s each (2026-10-24).

## 0x72 blocks (sel -> peripheral)

| sel | enables | len | oracle |
|---|---|---|---|
| 0x40 | EFB_I2C1 | 5 | `efb_i2c1` target |
| 0x4a | EFB_I2C2 | 5 | `efb_i2c2` target |
| 0x54 | EFB_SPI | 10 | this doc |
| 0x5e | EFB_TC | 18 | payload varies with timer config; not decoded |
| none | EFB_UFM, or nothing | | UFM alone emits no block: not recoverable |

## SPI block (sel 0x54) = registers 0x54..0x5D, byte i = register 0x54+i

| byte | reg | bits (measured) |
|---|---|---|
| 1 | SPICR1 | 0x80 SPE (set in every SPI stream), 0x40 SPI_WAKEUP |
| 2 | SPICR2 | 0x01 SPI_LSB_FIRST, 0x02 SPI_PHASE_ADJ, 0x04 SPI_CLK_INV, 0x28 SPI_SLAVE_HANDSHAKE (two bits), 0x80 SPI_MODE=MASTER |
| 3 | SPIBR | SPI_CLK_DIVIDER - 1 (master; divider 8 -> 0x07) |
| 4 | SPICSR | 0xFF in every stream |
| 9 | SPIIRQEN | 0x02 RXOVR, 0x04 TXOVR, 0x08 RXRDY, 0x10 TXRDY |
| 0,5,6,7,8 | | 0 in every build; any set bit is reported UNEXPLAINED by `efb_decode.py` |

- Master builds need `SYSCONFIG MASTER_SPI_PORT=ENABLE` in the LPF, else map errors.
- Board design payload `00 80 00 00 ff 00 00 00 00 00` == slave default: all SPI attributes at default, SPI_MODE SLAVE.
- Emitted as `EFB #(...)` parameters on the instance; blackbox module declares them.
- Tests: `tests/test_efb_decode.py` (payloads copied from the oracle builds).

## Input side (#100): lifted vs routing oracle

- Target `wb_in` (generated by `efb_oracle.py`): every WISHBONE input driven by its own flop, SPISCSN and WBCLKI by pads.
- `efb_oracle.py compare`: EFB input pin -> driver flop (slice letter + Q index), oracle `ncdread` vs lifted DB.
- Diamond slice sites are one column right of the lifter's tile column; the offset is identical for all 19 flop-driven pins.
- Result (2026-10-24): 20 / (20 matched + 0 missing + 1 wrong + 0 extra) EFB input pins.
- The 1 wrong: WBCLKI. Oracle: pad `clk` -> global spine (`JPCLKT01` -> `VPRXCLKI0`). Lifter: spine net has no link to the pad. Global-wire family, tracked in #109.
- SPISCSN now matches (pad net on `JCE0`, ordinary routing). In the board design `JCE0` is fed from `G_HSBX0201` (global), so it has no driver there: same #109 gap.
