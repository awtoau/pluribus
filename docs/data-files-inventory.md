Rule (Dan, 2026-10-29): evidence belongs in the per-family database (generic schema); no new JSON
data files. Classes: (a) config / human-edited → file; (b) test baseline or oracle → file (a gate
input must be a stable, reviewable file); (c) derived → regenerate from the DB, stop tracking;

## Write path (no new JSON)

- `provenance.evidence_io.record_specimen(conn, family, device, name, base, only_spec, only_base, meta,
  source_ref, generator, commit, bits_per_frame)` — one call per pair; idempotent. The paused specimen
  scripts replace their `json.dump` with this call (3–5 lines each) when resumed; `source_ref` then
  names the sweep (e.g. `sweep:m9k_bincode:w9`) instead of a file.
- `record_absence(...)` for never-exercised evidence; `record_decode(...)` for decoder / oracle / image runs.
- Read side for scripts that consumed the JSON shapes: `scripts/evidence_io_bridge.py`.
